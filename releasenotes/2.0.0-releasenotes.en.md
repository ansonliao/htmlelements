HtmlElements 2.0.0 Release Notes
================================

2.0.0 is the first release of this fork. It modernises the build and the
underlying Selenium dependency. Because the required Selenium and Java versions
changed, this release is **not** binary compatible with 1.x.

Distribution coordinates
------------------------

| | 1.x (upstream) | 2.0.0 (this fork) |
|---|---|---|
| groupId | `ru.yandex.qatools.htmlelements` | `io.github.ansonliao` |
| version | `1.17` / `1.18-SNAPSHOT` | `2.0.0` |

The `artifactId` values are unchanged (`htmlelements-java`,
`htmlelements-matchers`, `htmlelements-thucydides`, `htmlelements-all`), so
migration requires only the `groupId` and `version` to be updated. Java package
names are also unchanged (`ru.yandex.qatools.htmlelements`), so no source
changes are required on the consuming side.

Breaking changes
----------------

### Selenium 2.53.0 → 4.51.0

* `HtmlElement` and `TypifiedElement` now implement `org.openqa.selenium.WrapsElement`
  instead of the removed `org.openqa.selenium.internal.WrapsElement`.
* `ProxyFactory` produces proxies backed by
  `org.openqa.selenium.interactions.Locatable` (the `internal` package no longer exists).
  `getCoordinates()` remains available on proxied elements.
* `WebElementNamedProxyHandler` no longer depends on the removed
  `org.openqa.selenium.support.ui.Clock` / `SystemClock`.

### Java 8 → Java 21

The library is now compiled with `--release 21` and requires a Java 21 runtime.

### Thucydides → Serenity BDD

`htmlelements-thucydides` now depends on `net.serenity-bdd:serenity-core` 5.4.1
instead of the discontinued `net.thucydides:thucydides-core` 0.9.275, which
transitively required Selenium 2.x and could not coexist with Selenium 4.

`BlockPageObject` source is unchanged: `net.thucydides.core.pages.PageObject`
is still provided by Serenity under its historical package name.

### PhantomJS removed

`com.github.detro:phantomjsdriver` and `phantomjs-maven-plugin` were removed.
PhantomJS has been unmaintained since 2018, was never referenced by this
project's sources, and its bundled binary does not run on Apple Silicon.

### Build system

Apache Maven was replaced by Gradle (Kotlin DSL, version catalog, wrapper).
There is no `pom.xml` in the repository; use `./gradlew build`.

Behaviour changes
-----------------

### `TextInput#getText()`

Selenium 4 applies W3C semantics to `WebElement#getAttribute`, so
`getAttribute("value")` returns the HTML *attribute* rather than the value the
user has typed. `TextInput#getText()` now uses `getDomProperty("value")`, which
restores the pre-2.0 behaviour of returning the current input value.

### `HtmlElementUtils#isOnRemoteWebDriver(WebElement)`

The previous implementation read the protected `RemoteWebElement.parent` field
through reflection. It now uses the public `RemoteWebElement#getWrappedDriver()`
API, removing a dependency on a Selenium internal field layout.

### `WebElementNamedProxyHandler`

The stale-element retry loop always performs at least one attempt and no longer
can throw a `NullPointerException` when the configured timeout is `0` seconds.

### `HtmlElementUtils#newInstance(Class, Object...)`

`Class#newInstance()` (deprecated since JDK 9) was replaced with
`getDeclaredConstructor().newInstance()`. The transitive, undeclared Guava
`Lists` usage was also removed.

Dependency upgrades
-------------------

| Dependency | 1.x | 2.0.0 |
|---|---|---|
| Selenium | 2.53.0 | 4.51.0 |
| Serenity BDD | — (Thucydides 0.9.275) | 5.4.1 |
| JUnit | 4.12 | 4.13.2 |
| Mockito | 1.10.19 (`mockito-all`) | 5.24.0 (`mockito-core`) |
| Hamcrest | 1.3 (`hamcrest-all`) | 2.2 |
| commons-lang3 | 3.4 | 3.21.0 |

`org.hamcrest.Factory` was removed in Hamcrest 2.x. The annotation has been
dropped from the matcher factory methods; this has no effect on callers, since
the methods are still ordinary public static factories.
